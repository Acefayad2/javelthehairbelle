# Javel The Hair Belle

Portfolio site for [@javelthehairbelle](https://www.instagram.com/javelthehairbelle/). Plain HTML, CSS and JS.

All content comes from public Instagram posts and the bios of @javelthehairbelle and @javelxo. Each gallery item in `build.py` keeps its source post, caption and alt text. Edit that list, then run:

```bash
python3 build.py
```

`index.html` is generated, so edit `build.py` rather than the HTML.

No prices, policies, reviews, phone numbers or email addresses are on the site, because none are on her Instagram pages.

Booking is a request form handled by Netlify Forms (form name `booking`). The style list in `build.py` comes from her captions and hashtags.
